# PROJECT REQUIREMENTS

## WHAT TO CREATE

Entrants must build an agentic application that:

* Uses CockroachDB as its persistent memory layer.
* Is deployed on AWS.

Each application is referred to as a "Project."

All required CockroachDB and AWS components must be meaningfully integrated into the Project, not simply initialized.

## COCKROACHDB REQUIREMENTS

Your Project MUST use at least 2 of the following CockroachDB tools:

1. CockroachDB Cloud Managed MCP Server

   Connect AI agents directly to CockroachDB clusters with a single configuration snippet from the Cloud Console.

   Features:

   * Works natively with Claude Code, Cursor, and VS Code.
   * Safe by default with read-only mode.
   * Full audit logging.
   * No custom proxy required.

   Endpoint:
   https://cockroachlabs.cloud/mcp

2. CockroachDB Distributed Vector Indexing

   Store and query embeddings at scale using CockroachDB's vector support with distributed indexing.

   Benefits:

   * Semantic search and retrieval remain fast as data grows.
   * No separate vector store to maintain.
   * No reindexing pain.
   * No consistency gaps between vector data and the operational database.

   Ideal for:

   * RAG pipelines
   * Long-term agent memory
   * Semantic search applications

3. ccloud CLI (Agent-Ready)

   Give your agent direct, secure access to the full CockroachDB Cloud control plane.

   Capabilities include:

   * Provisioning clusters
   * Managing backups
   * Configuring networking
   * Monitoring audit logs

   Designed for AI with:

   * Consistent noun-verb command patterns
   * JSON output on every command
   * Granular service-account-based RBAC

4. CockroachDB Agent Skills Repo (Open Source)

   A curated, open-source collection of machine-executable Agent Skills encoding CockroachDB expertise.

   Skills cover:

   * Onboarding
   * Query and schema design
   * Operations
   * Performance
   * Security
   * Observability

   Portable across:

   * Claude
   * Cursor
   * LangChain
   * Any MCP-compatible client

## AWS REQUIREMENTS

Your Project MUST use at least 1 AWS service, including but not limited to:

* Amazon Bedrock

  * Foundation models
  * Knowledge bases
  * Agents

* AWS Lambda

  * Serverless agent execution

* Amazon ECS / EKS

  * Containerized agent workloads

* Amazon S3

  * Artifact or document storage

* Amazon SageMaker

  * Model training or inference

* Amazon Bedrock Agents

  * Multi-step agentic workflows

* Any other AWS service that powers your agent's environment

## FUNCTIONALITY

The Project must:

* Be successfully installable.
* Run consistently on its intended platform.
* Function as depicted in the demonstration video and/or described in the written submission.

## PLATFORMS

The submitted Project must run on the platform for which it is intended, as specified in the Submission Requirements.

## NEW PROJECTS ONLY

Projects must be newly created by the Entrant during the Submission Period.

Participants MAY use standard development tools, including:

* Frameworks
* Libraries
* Starter templates
* AI coding assistants

However:

* Any other pre-existing code or work incorporated into the Project must be disclosed.
* The work described and submitted must have been built during the Submission Period.

## THIRD-PARTY INTEGRATIONS

If the Project integrates any third-party:

* SDK
* API
* Data

the Entrant must be authorized to use it in accordance with all applicable terms, conditions, and licensing requirements.

# SUBMISSION REQUIREMENTS

Submissions to the Hackathon must meet the following requirements:

1. PROJECT

---

Include a Project that:

* Uses the required developer tools.
* Meets all Project Requirements listed above.

2. PUBLIC CODE REPOSITORY

---

Provide a URL to your code repository for judging and testing.

The repository must:

* Be public.
* Be open source.
* Contain all necessary source code.
* Include clear README documentation.
* Include all required dependencies.
* Include example configurations or datasets, if applicable.
* Include complete setup and run instructions.
* Include an open-source license file.

Recommended licenses:

* MIT
* Apache 2.0

The license should be detectable and visible at the top of the repository page, including in the repository's "About" section.

3. FUNCTIONAL DEMO APP

---

Provide a URL to your functional demo application.

4. PROJECT DESCRIPTION

---

Include a written description explaining:

* The features of the Project.
* The functionality of the Project.
* How the Project works.

5. DEMONSTRATION VIDEO

---

Include a demonstration video of the Project.

The video:

* Should be less than 3 minutes.
* Judges are not required to watch beyond 3 minutes.
* Must show the Project functioning on the device/platform for which it was built.
* Must show the CockroachDB memory layer actively working.
* Must be uploaded publicly to YouTube or Vimeo.
* Must include a link to the video in the Hackathon submission form.
* Must not include third-party trademarks, copyrighted music, or other copyrighted material unless the Entrant has permission to use it.
