BRASS TACKS OWNER PRODUCTION UI V38 - DROP-IN PATCH
==================================================

WHAT THIS PATCH CONTAINS
------------------------
site/app.html
  Source UI with the owner production system v38.

backend/tests/test_site_build.py
  Regression tests covering the Growth cleanup, dark Maker/chat controls,
  status pills, dropdowns, profile controls, logo treatment, and Memory Engine
  isolation.

web/app/index.html
  Prebuilt app page for direct frontend deployment. Rebuilding from source is
  still recommended so the generated site uses your current API environment.

APPLY FROM POWERSHELL
---------------------
1. Open the repository root:

   cd C:\Users\ra067138\Documents\tutorial\SU\concepts\aws-cockroach-hackathon-live

2. Save or commit any work you need to keep, then extract this ZIP directly at
   the repository root:

   Expand-Archive `
     "$env:USERPROFILE\Downloads\aws-cockroach-hackathon-owner-production-v38-drop-in-patch.zip" `
     -DestinationPath . `
     -Force

   This archive has no wrapper directory. It replaces the real project files.

3. Confirm the source marker exists:

   Select-String -Path ".\site\app.html" -Pattern "owner-production-system-v38"

4. Rebuild the complete static site:

   py .\scripts\build_web.py

5. Run the UI regression suite:

   py -m pytest .\backend\tests\test_site_build.py -q

6. Commit the tracked source files:

   git add site\app.html backend\tests\test_site_build.py
   git commit -m "Polish Growth chat controls and owner theme"
   git pull --rebase origin main
   git push origin main

DEPLOY THE FRONTEND
-------------------
Use the existing GitHub Actions frontend workflow, or upload the rebuilt web\
directory to the existing S3 website bucket and invalidate CloudFront.

Do not upload this patch ZIP itself to S3. Deploy the contents of web\ after
running scripts\build_web.py.

WHAT CHANGED
------------
- Growth subtitles and empty-state paragraphs were removed.
- Empty Growth panels collapse to a minimal title-and-count row.
- Complete Maker drafts use a dark, bounded, scrollable reading surface.
- Ready, Archived, Link clicked, warning, and failure pills use dark semantic
  colors with high-contrast text.
- Return-to-For-You selects and native options use the dark control theme.
- Reconsider controls now have clear labels and consistent spacing.
- Maker buttons, chat send, Undo Pass, and profile Save share one primary action
  language.
- Brass Tacks owner-facing logo colors use a consistent violet/plum gradient.
- Memory Engine styling remains unchanged.
