Straight answers

What this is, and what it isn't.

Built for the AWS + CockroachDB hackathon. Worth being plain about the edges.

  • Rosa's Trattoria is not a real restaurant. The corpus is hand-written so the demo is reproducible and carries nobody's real reviews.
  • The numbers are real anyway. Every figure on this page and in the demo is queried out of a live CockroachDB cluster, not typed into the markup.
  • Reasoning runs on the Anthropic API, not Bedrock. AWS could not grant this account any current Claude model. Embeddings still run on Bedrock Titan, so retrieval is AWS end to end.
  • No account, and nothing to save. The demo is read-only: your clicks live in the browser and vanish on refresh.
